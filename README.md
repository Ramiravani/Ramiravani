# ربات تلگرام فروش منابع دیجیتال

این ربات برای فروش منابع دیجیتال مانند دوره‌های آموزشی، کتاب‌های الکترونیکی، نرم‌افزارها و قالب‌ها طراحی شده است.

## ویژگی‌ها

### برای کاربران:
- 🛍️ مشاهده محصولات بر اساس دسته‌بندی
- 💳 سفارش‌گذاری و انتخاب روش پرداخت
- 📋 پیگیری سفارشات
- ℹ️ اطلاعات تماس و درباره ما

### برای مدیران:
- ➕ افزودن محصولات جدید
- 📊 مشاهده آمار فروش
- 📋 مدیریت سفارشات (تأیید، لغو، ارسال)
- 👥 مشاهده لیست کاربران

## فایل‌های مهم

- `main.py` - اجرای ربات در حالت polling
- `webhook_server.py` - سرور Flask برای webhook
- `config.py` - تنظیمات ربات
- `database.py` - مدیریت پایگاه داده JSON
- `handlers.py` - پردازش پیام‌های کاربران
- `admin_handlers.py` - پردازش پیام‌های مدیران
- `keyboards.py` - صفحه‌کلیدهای ربات

## نحوه اجرا

### روش 1: اجرای محلی (Polling)
```bash
python3 main.py
```

### روش 2: اجرای با Webhook
```bash
python3 webhook_server.py
```

## تنظیمات

1. فایل `.env` را ویرایش کنید:
```
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
```

2. فایل `config.py` را ویرایش کنید:
- `ADMIN_IDS`: شناسه‌های کاربری مدیران
- `PRODUCT_CATEGORIES`: دسته‌بندی محصولات
- `PAYMENT_METHODS`: روش‌های پرداخت

## افزودن محصولات

### روش 1: از طریق ربات
1. پیام `/admin` را ارسال کنید
2. گزینه "➕ افزودن محصول" را انتخاب کنید
3. مراحل را دنبال کنید

### روش 2: از طریق کد
فایل `sample_data.py` را اجرا کنید تا محصولات نمونه اضافه شوند:
```bash
python3 sample_data.py
```

## مدیریت سفارشات

1. پیام `/admin` را ارسال کنید
2. گزینه "📋 مدیریت سفارشات" را انتخاب کنید
3. وضعیت سفارشات را تغییر دهید:
   - ✅ تأیید
   - ❌ لغو
   - 📦 ارسال شده

## پایگاه داده

ربات از فایل JSON برای ذخیره اطلاعات استفاده می‌کند:
- `bot_database.json` - شامل کاربران، محصولات و سفارشات

## استقرار

### Heroku
1. فایل‌های `Procfile`، `requirements.txt` و `runtime.txt` آماده شده‌اند
2. ربات را به Heroku push کنید
3. webhook را تنظیم کنید

### سایر سرویس‌ها
ربات با هر سرویس میزبانی که از Python و Flask پشتیبانی می‌کند، سازگار است.
